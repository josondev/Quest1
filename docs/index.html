What is Quest1?

Quest1 is an end-to-end AI-powered media analysis system that locates target spoken or visual dialogue inside video content. Given a video URL and a target dialogue string, it determines the exact timestamp, frame number, confidence score, and a verified frame image.

Instead of relying on a single modality, Quest1 chains subtitle analysis, Whisper speech recognition, Mistral OCR visual search, and Llama Vision Model arbitration into a progressive fallback pipeline that short-circuits at the cheapest successful tier.

Detection Pipeline

T0
Embedded Subtitle Match
T1
Whisper STT Alignment
T2
Sparse OCR Timeline
T3
Dense OCR Confirmation
T4
VLM Arbiter Fallback

VLM is only invoked when all cheaper methods fail or return confidence below 0.85.

REST API

POST /api/v1/jobs Submit a detection job — returns job_id immediately
GET /api/v1/jobs/{job_id} Poll status and retrieve full result
GET /api/v1/jobs/{job_id}/frame Download the detected frame as JPEG

Example

curl -X POST http://localhost:8000/api/v1/jobs \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.youtube.com/watch?v=dQw4w9WgXcQ","target_text":"Never gonna give you up"}'
{
  "job_id": "job_4a2f1c8b3e",
  "status": "completed",
  "timestamp_seconds": 18.72,
  "formatted_timestamp": "00:00:18.720",
  "frame_number": 468,
  "confidence_score": 0.94,
  "tier_executed": "Tier 1: STT Acoustic Match",
  "extracted_text": "Never gonna give you up"
}
